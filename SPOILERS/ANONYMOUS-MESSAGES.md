# Anonymous messages

Many messages appear as:

```
SOURCE: UNKNOWN
ID: 17-A
AUTHENTICITY: UNVERIFIED
```

The player must not immediately know who sent them. Every message has a **fair** speaker, recoverable by Season IV from fingerprints that were always on the page.

## Rules for writers

1. Unknown ≠ unsolvable.
2. Some messages are genuine, some manipulated, some truthful-but-misleading, some from future information.
3. Fingerprints must exist in the same season the message appears, even if they only pay off later.
4. Never require a player to message a real person to learn a sender.
5. Future Player may use the current player's punctuation from the ident string and decoder submissions — that data is already in the save file.
