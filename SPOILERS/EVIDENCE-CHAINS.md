# Evidence chains

A chain is a sequence of filings that must remain valid when a later season reinterprets them.

## Chain A — The clock is an address

1. Header shows 03:17 (environmental).
2. Filing 0317 yields VW-317 (I).
3. Room 317 contains the tuner 440.17 (II).
4. Badge log 03:17:17 after disappearance (II).
5. Beat frequency 17.17 (III).
6. Slot 17 instance A (IV).

Nothing in the chain is overwritten. IV names what 17 always was.

## Chain B — Vesper is not a password

1. Acrostic VESPER in Nora's notes (I).
2. Used as vault segment (I).
3. Revealed as wing name (II).
4. Revealed as palace walking order (II).
5. Hymn title (III).
6. Place-term in the identity formula (IV).

Players who treated it as "just a password" still used it correctly. They simply had not read the edge.

## Chain C — Zero writes back

1. Spectrogram ZERO (I).
2. Morse STILL HERE (I).
3. Interview reversed STILL HERE (III).
4. Protocol WRITE arrow (III).
5. File 07 = daybook name (IV).
6. Player is instance 17-A of Subject Zero (IV).

## Chain D — Observer fabricates

1. DIR-11 second checksum (I).
2. OBS-1 uses player name (I).
3. OBS-2 (II).
4. 17-C too eager to declare Nora dead (II).
5. Speaker table marks 17-C fabricated (IV).
6. Remain ending is the Observer's job offer (IV).

## Chain E — Nora extracted herself

1. Daybook: "I will swipe after they file me missing" (I).
2. Badge after disappearance (II).
3. Palace walking her notes (II).
4. Delete arrow is a lie (III).
5. Extract protocol is her last margin (IV).

## How to add a chain

Do not add a Season II clue that contradicts a Season I filing. Add an edge that makes the old filing mean more.
