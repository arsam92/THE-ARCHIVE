# Fake documents (in-world props)

All documents are original fiction. They exist only inside the game and this repository.

## Design rules

- Letterhead: Halcyon Records Facility / Vesper Wing / NODE 17-A
- Paper is warm. Terminal is cold. Mixing them is a clue (Observer interpolation lives on paper).
- Every document has one **honest** metadata lie or one honest metadata truth — never both, never neither.
- UV inspect reveals hidden ink already in the layout. No print-and-scan required.
- No real logos, no real agencies, no real addresses.
