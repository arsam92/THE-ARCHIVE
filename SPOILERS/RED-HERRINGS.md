# Believable red herrings

A red herring must be **locally plausible** and **globally false**. It must fail a checksum the player already knows how to run.

| Herring | Why it looks true | Why it is false | How it dies fairly |
| --- | --- | --- | --- |
| Vigenère key UNKNOWN | The header says SOURCE: UNKNOWN | Identifiers are numeric keys in this facility | ARG-I-01 hint names shift |
| HALCYON as passphrase | Letterhead, all caps | Letterhead never files | UV: "HALCYON is a letterhead" |
| Dates on Nora's notes as a number code | Six dates invite arithmetic | They are dates | Acrostic pays, dates never do |
| 440 as Caesar shift | Number sitting next to letters | 440 > 26 and is a frequency | Spectrogram is visible |
| Record 12 is the secret | Last items feel hidden | Wound is record 07 | Index labels the hole |
| Elias 04:04 badge error | Pattern-matching "glitch rows" | Planted decoy | Sort-by-time leaves it meaningless |
| Left channel "I am Elias" | Clear voice, named character | Channel is the lie | Reverse the other ear |
| Musical notes A–G as cipher | Hymn invites it | Alphabet too small for VESPER | Titles acrostic instead |
| Instance B is the real player | Sequel bait | Empty slot | Index shows B unassigned |
| DELETE ending | Video-game third button | Observer trap, checksum fail | Button refuses to file |
| Nora died in a fire | Classic archive myth, also CASE-404-adjacent | Not this story | Badge swipe after "death" |
| Real-world facility to visit | Maps look coastal | Fictional. Not visitable. | Safety copy on every map prop |

Never let a herring require a dangerous or illegal action to disprove. Disproof is in-game.
