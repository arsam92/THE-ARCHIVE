# ARG safety (non-negotiable)

THE ARCHIVE should feel real. It must not require unsafe real-world action.

## Never require

- Illegal activity
- Trespassing
- Harassment
- Doxxing
- Contacting real-world strangers
- Dangerous behaviour
- Visiting real buildings, coordinates, or facilities
- Calling real phone numbers
- Using real people as if they were characters

## Official surfaces

- The game client
- This GitHub repository (`arsam92/THE-ARCHIVE`)
- In-game Board and Decoder

If a clue appears to point off those surfaces, it is a **red herring** or a **metaphor**. Maps of Vesper Wing are fictional.

## Community

Players may discuss theories on official Discussions. They must not:

- Investigate real names from the fiction as if they were living people
- Use real books, private messages, or strangers as cipher keys
- Create fake emergency reports

ARG-III-03's book cipher uses **only in-game documents**.

## Tone of the Observer

The Observer files the player. It does not threaten real harm. Keep watchdog copy archival, not stalking.

## This file overrides flavour

If a puzzle is interesting and unsafe, the puzzle is wrong. Rewrite it.
